# nichtsam.com 設計規格

這份文件是網站重建的依據。改設計時先改這裡，再改程式。

- 狀態：第一階段（app 本身）
- 概念原型：鉛筆線框稿（v5 sheet），火柴人已排除，角色之後另外設計

## 1. 概念

整個網站像一張用鉛筆畫的網頁線框稿。所有框、線、圖示都是手繪的，
內容進入畫面時被「畫出來」，離開畫面時被「擦掉」，換頁時整個畫面被來回塗滿再擦開。

原則：

1. 內容永遠第一。任何動畫都是增強，拿掉之後網站照樣完整可用。
2. 安靜。只有有意義的動作會動：畫出、擦掉、轉場、翻頁。沒有自己一直在跑的東西。
3. 黑白鉛筆，只在極少數地方用一點橘色（游標、hover、焦點）。

## 2. 視覺語言

### 2.1 鉛筆線條

- 由自製的產生器（`app/ui/public/pencil.ts`）產生 SVG 路徑，伺服器和瀏覽器共用同一份程式碼。
- 固定種子：同一個元素在伺服器和瀏覽器、每次載入都畫出一樣的線。
- 框的畫法：每一邊畫兩筆，稍微錯開，轉角畫超出去。
- 長線（整張紙的外框）彎曲要收斂，避免在手機上擠到內容。
- 陰影只用斜線排線（hatch），光源在左上，陰影落在右下。

### 2.2 字體

| 用途                       | 字體                        |
| -------------------------- | --------------------------- |
| 標題、導覽、註解、介面文字 | Architects Daughter（手寫） |
| 主視覺大標                 | Architects Daughter 大寫    |
| 文章內文                   | Karla                       |
| 程式碼                     | JetBrains Mono              |

### 2.3 顏色

| Token                 | 白天      | 夜晚      |
| --------------------- | --------- | --------- |
| `--paper` 紙          | `#f4f3ef` | `#161615` |
| `--ink` 墨            | `#1d1d1b` | `#eceae4` |
| `--ink-soft` 次要文字 | `#62615c` | `#a6a59f` |
| `--pencil` 線條       | 墨色 86%  | 墨色 86%  |
| `--hatch` 排線        | 墨色 45%  | 墨色 40%  |
| `--accent` 強調       | `#b8480a` | `#ff8a45` |

夜晚模式是「黑紙白墨」，不是另一套配色。

所有文字顏色和背景的對比都達到 WCAG AA（4.5:1 以上），強調色因此在白天用較深的橘。

## 3. 頁面與網址

| 網址                          | 頁面                             |
| ----------------------------- | -------------------------------- |
| `/`                           | 首頁                             |
| `/about`                      | 關於                             |
| `/projects`                   | 專案列表                         |
| `/projects/:slug`             | 單一專案                         |
| `/articles`                   | 文章列表                         |
| `/articles/:slug`             | 單篇文章                         |
| `/articles/feed.xml`          | RSS                              |
| `/sitemap.xml`、`/robots.txt` | SEO                              |
| `POST /theme`                 | 切換日夜（沒有 JavaScript 時用） |
| 其他                          | 404                              |

每一頁都是伺服器渲染的完整 HTML，直接打開網址、重新整理都正常。

### 3.1 首頁

由上而下：

1. 主視覺框：雙線外框、四角角標、左右箭頭、下方圓點，三張可以翻的內容。
   - 自我介紹，配書桌插圖（檯燈可以點，切換日夜）。
   - 文章，配書本插圖，連到最新一篇文章。
   - 專案，配瀏覽器草稿插圖，連到專案列表。
2. About：手寫標題加底線，兩欄文字，連到 `/about`。
3. Projects：方格卡片（方框裡一個圖示，下面寫標題），最後一格是 GitHub。
4. Articles：文章列表，每列有標題、日期、閱讀時間，底下一條鉛筆線。
5. 頁尾：一條分隔線，下面三欄（站內連結、外部連結、版權）。

### 3.2 其他頁

- 共用同一張紙、同一個導覽列和頁尾。
- 頁首是手寫大標題加底線，上方一行小字（日期、分類之類）。
- 文章內文限制行寬（約 68 字元），程式碼區塊日夜各一套配色。

## 4. 元件

| 元件   | 說明                                                                      |

| Sheet  | 整張紙的鉛筆外框，包住整個網站                                            |
| Header | 左邊手寫的 `nichtsam`，右邊導覽連結和日夜切換；目前所在頁面下方有手畫底線 |

| Footer | 分隔線與三欄                                                              |

## 5. 動態

### 5.1 畫出與擦掉

- 線條用 `stroke-dashoffset` 一筆一筆畫出來；文字由左到右「寫」出來。
- 進入畫面時畫出，離開畫面前在接近邊緣處擦掉，讓擦的過程看得到。
- 元素大小改變時（例如縮放視窗），框線先跟著伸縮，下一幀用同一個種子重畫。

### 5.2 換頁轉場

- 一條連續的鋼筆線斜向鋸齒來回塗三趟，把畫面塗滿；最後補一層墨色填掉小縫。
- 換頁內容在塗滿之後才替換，接著從左到右擦開。
- 時間約 1.2 秒（塗 0.64、停 0.07、擦 0.46）。
- 只用在站內連結。上一頁、下一頁、外部連結、另開分頁都不做轉場。

### 5.3 主視覺翻頁

- 按箭頭或圓點：目前的內容先被擦掉，再畫出下一張。
- 不會自動輪播。

## 6. 無障礙、響應式、SEO、沒有 JavaScript

這一節是硬性要求。

### 6.1 沒有 JavaScript 時

- 所有內容一開始就看得到，不依賴動畫才出現。
- 連結是一般的換頁。
- 主視覺三張內容改成可以橫向捲動的列（scroll-snap），全部都讀得到。
- 日夜切換是一個表單，送出到 `POST /theme`，由伺服器設定 cookie 後導回原頁面。
- 「先藏起來再畫出來」的狀態只在 JavaScript 確定會執行時才啟用；
  如果 JavaScript 載入失敗，幾秒後自動恢復成全部顯示。

### 6.2 減少動態（`prefers-reduced-motion: reduce`）

- 不做畫出、擦掉、轉場、翻頁動畫，內容直接出現、直接替換。
- 滑鼠 hover 的位移效果也關掉。

### 6.3 鍵盤與螢幕報讀器

- 第一個可聚焦的元素是「跳到主要內容」。
- 所有互動都是原生元素（`a`、`button`、`form`），焦點樣式清楚可見（橘色虛線框）。
- 主視覺使用輪播的 ARIA 模式：區塊標示為 carousel，每張標示「第幾張，共幾張」，切換時用 live region 告知。
- 日夜切換按鈕用 `aria-pressed` 表示目前狀態。
- 換頁後把焦點移到主要內容，並更新頁面標題。
- 裝飾性的線條和插圖都對報讀器隱藏；有意義的插圖提供文字說明。

### 6.4 響應式

- 以手機為基準，版面在 320px 寬也不會橫向捲動。
- 字級、間距用 `clamp()` 隨螢幕縮放。
- 斷點大約在 40rem（手機到平板）和 60rem（平板到桌機）：
  - 導覽列在窄螢幕換到 logo 下方。
  - 主視覺在窄螢幕改成上下排列。
  - 專案方格依寬度自動排成 1 到 3 欄。
  - 頁尾三欄在窄螢幕變成一欄。
- 可點擊的區域至少 44×44px。
- 支援瀏海與圓角螢幕（safe-area）。

### 6.5 SEO

- 每頁有自己的 `title`、`description`、canonical URL、Open Graph 與 Twitter 卡片資訊。
- 結構化資料：首頁與關於頁用 `Person`，文章用 `BlogPosting`。
- `sitemap.xml` 包含所有頁面，`robots.txt` 指向它，另提供文章 RSS。
- 語意化 HTML：每頁一個 `h1`，標題層級不跳級，使用 `header`、`nav`、`main`、`footer`、`article`。

## 7. 技術架構

採用 Remix 3 官方建議的結構。

```txt
server.ts                    Node 伺服器入口
app/
├── routes.ts                網址合約（唯一來源）
├── router.ts                middleware 與 controller 對應
├── middleware/theme.ts      讀取主題 cookie
├── assets.ts                瀏覽器模組與樣式表
├── content/                 文章、專案、網站設定
├── actions/                 各路由的 controller 與頁面
│   ├── controller.tsx       首頁、關於、主題、SEO 檔案、404
│   ├── projects/
│   ├── articles/            （含 RSS）
│   └── public/entry.ts      啟動瀏覽器端執行環境
└── ui/                      共用版面與元件
    ├── document.tsx         HTML 外殼與 SEO 標籤
    ├── layout.tsx           Sheet、Header、Footer
    ├── headings.tsx         段落標題、頁首標題
    ├── lists.tsx            專案方格、文章列表
    └── public/              瀏覽器也會用到的程式碼
        ├── pencil.ts        鉛筆線產生器與會跟著尺寸重畫的形狀
        ├── doodles.ts       固定比例的插圖與圖示
        ├── sketch.tsx       <Sketch>、<Doodle> 元件
        ├── ink.tsx          畫出、擦掉、跟著尺寸重畫
        ├── page-transition.tsx  換頁轉場
        ├── hero.tsx         主視覺翻頁
        ├── theme-toggle.tsx 日夜切換
        └── site.css         設計 token 與全站樣式
```

- 換頁：Remix 內建的站內導航（Navigation API）負責換頁，轉場只是包在 `navigate()` 外面的動畫。
  不支援 Navigation API 的瀏覽器就是一般換頁。
- 主題：伺服器從 cookie 讀取主題並直接輸出，換頁時不會閃。
- 會被瀏覽器程式碼接手的節點（轉場圖層、JavaScript 開關）標記 `data-rmx-preserve-dom`，站內換頁時不會被覆寫。
- 不使用 roughjs，鉛筆線由自製產生器輸出，伺服器與瀏覽器共用。

## 8. 範圍
